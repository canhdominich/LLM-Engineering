# Data card: Giao Hang Anh Ti delivery requests (simulated)

Generated by `make_requests.py` (seed 42): `uv run python make_requests.py` rewrites `delivery_requests.csv` byte for byte. Every message is simulated from 10 hand-written Vietnamese templates; no real customer wrote them.

File `delivery_requests.csv`, UTF-8, 40 rows, one chat message asking Giao Hang Anh Ti to pick up goods and deliver them inside Pho Rom Ra.

Columns (gold labels):
- `request_id`: R01 to R40.
- `text`: the message.
- `pickup_district`, `dropoff_district`: ASCII district names from `lab/m01/data/DATA_CARD.md` (Dau Pho, Cau Go, Xom Vui, Ben Song, Bai Bien, Cho Moi, Doi Thong, Khu Cong Nghiep). Always different from each other.
- `items`: integer 1 to 12; written as a word (một, hai, ba, bốn, năm) in about a third of the messages where the number is 5 or less.
- `cod_vnd`: cash on delivery in VND, integer. 0 when the message says prepaid (khách trả trước, đã chuyển khoản, không thu tiền). Written in mixed forms: `250k`, `250.000đ`, `250 nghìn`, `250000 đồng`, `1tr2`, `1,2 triệu`.
- `service`: `express` when the message has an urgency cue (gấp, hỏa tốc, trong 1 tiếng, giao nhanh), else `standard`.

Generating rules: template i % 10 for row i; districts sampled without replacement; 30% of messages lose diacritics and become lower case. One template puts the drop-off district first ("Đầu Phố nhận 4 gói từ ... ở Bãi Biển"), which is the main trap for extractors that rely on word order.

Known limits: short, template-like messages; no message mixes two requests; no missing fields (lessons add incomplete and non-request messages by hand).
